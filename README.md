# Python Day 166 – Website Uptime Monitor

## Project Description
A Python application that checks whether multiple websites are responding and generates a CSV report containing their HTTP status and response times.

## Features
- Monitor multiple websites.
- Check websites concurrently using threads.
- Detect HTTP responses and connection failures.
- Measure response time.
- Generate a CSV report.
- Display online and offline statistics.

## Technologies Used
- Python
- Threading
- urllib
- CSV
- DateTime

## Files
- `uptime_monitor.py` – Main application.
- `uptime_report.csv` – Generated report.

## How to Run
Run `python uptime_monitor.py`.

No external Python packages are required.

## Learning Outcomes
Learned HTTP requests, multithreading, synchronization using locks, exception handling, and CSV report generation.
